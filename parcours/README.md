# Parcours de Formation SkillAfrik

Ce dossier contient les pages détaillées pour chaque parcours de formation proposé par SkillAfrik.

## Fichiers disponibles

1. **culture-numerique.php** - Parcours d'initiation aux compétences numériques de base
2. **cyber-academy.php** - Formation avancée en cybersécurité
3. **developpement-web.php** - Apprentissage du développement web full-stack
4. **developpement-mobile.php** - Formation au développement d'applications mobiles
5. **marketing-numerique.php** - Stratégies de marketing digital et de communication en ligne

## Structure d'une page de parcours

Chaque page de parcours suit la même structure :

1. **En-tête héro** avec image de fond et titre accrocheur
2. **Description détaillée** du parcours
3. **Liste des compétences** acquises
4. **Public cible**
5. **Liste des cours** associés au parcours

## Images

Les images des parcours sont stockées dans `public/images/parcours/` avec la convention de nommage suivante :
- `[nom-du-parcours]-bg.jpg` pour les images d'en-tête (1200x600px)
- `[nom-du-parcours]-thumb.jpg` pour les vignettes (400x200px)

## Mise à jour

Pour ajouter un nouveau parcours :
1. Créez une nouvelle page PHP dans ce dossier
2. Ajoutez les images correspondantes dans `public/images/parcours/`
3. Mettez à jour la page d'accueil pour inclure le nouveau parcours
4. Mettez à jour ce fichier README
